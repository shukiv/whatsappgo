# WhatsAppGo v0.1.6

## Fixes

- Jump to the newest message when sending text or explicitly opening a chat,
  including cached conversations and late layout updates. Ordinary wheel
  scrolling and quoted-message navigation retain control of the view.
- Constrain captioned image/video bubbles to a compact maximum width, removing
  the empty space beside previews while retaining readable caption padding.
- Clear stale typing/recording indicators after ten seconds without another
  activity update, and immediately on pause, offline or disconnection events.
- Move the account unread badge to the outer top-right of the profile button.
- Preserve quoted replies when file or voice sends fail. Late acknowledgements
  cannot clear a newer quote or another account/chat's draft.
- Prevent a delayed Copy image result from inserting a foreign message into
  the currently open conversation.
- Correct cancelled-download accounting so reconnects retain the three-download
  concurrency limit.

## Bug reporting

The toolbar and Help menu now open
[WhatsAppGo GitHub issues](https://github.com/shukiv/whatsappgo/issues) directly
in the default browser. No in-app intake form, API key or Turnstile challenge is
required, and no chat logs or diagnostics are automatically uploaded.

The legacy authenticated intake RPC remains available for tooling, but is not
used by either desktop reporting action. It still requires an operator-supplied
key and a working intake service; its cooldown handling and credential redaction
have been hardened. The old intake service is no longer the supported desktop
reporting destination.

## Compatibility and verification

Existing profiles and the maximum-local-history retention policy are preserved.
Disappearing-message timers do not expire locally stored conversation history.
Voice and video calls remain unsupported.

Verification uses the existing Go and desktop suites, isolated offscreen UI
checks, and CI desktop builds/tests on Linux, Windows and macOS. No live WhatsApp
messages or production bug reports are sent by these checks.

Release artifacts are the Linux AppImage, Windows installer and portable ZIP,
and macOS Apple Silicon DMG, accompanied by `SHA256SUMS`. Builds are unsigned:
Windows SmartScreen may warn, and macOS may require allowing the application
in System Settings. Verify checksums before installation. The release remains
a draft until a human reviews and publishes it.
