# WhatsAppGo v0.1.8

This release brings together the completed desktop parity batches, including a 50-acceptance-item batch compared with authenticated WhatsApp Web through Playwright. It does not imply full WhatsApp feature parity.

## Highlights

- Expanded group creation and management, participant mentions and named typing indicators.
- Improved participant-name rendering, clickable mentions, pinned-chat synchronization, and sticker cache recovery.
- Improved message menus, reaction placement, keyboard navigation, theme switching, and photo viewing.
- Searchable starred messages with exact-message navigation, clearer search results, loading and failure feedback, and keyboard controls.
- Calendar navigation to messages in locally stored chat history.
- Video volume, mute, playback speed, seeking, and fullscreen controls.
- Shared-media and global-media selection with bulk star, unstar, and download actions.

## Validation

The latest parity batch passed 89 focused native checks in each theme, 44 desktop tests, Go tests and vet, and isolated date-query regression checks. Earlier batches have separate validation recorded in the parity audit. Live reference inspection did not send test messages.

## Known limitations

- Starred-message search currently covers the latest 100 loaded starred messages.
- Calendar navigation searches local history, not unloaded server history.
- Older-media pagination, full-library sorting and filtering, bulk local deletion, unstar-all, and video picture-in-picture remain follow-up work.
- Voice and video calls are not supported.

## Installation

Download the artifact for your platform and verify it against `SHA256SUMS` before installation. Builds are unsigned: Windows SmartScreen may warn, and macOS may require approval in System Settings. The release remains a draft until the packaged binaries have been reviewed.
