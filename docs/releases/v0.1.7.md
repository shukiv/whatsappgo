# WhatsAppGo v0.1.7

## Contact sharing and profile photos

- Add paperclip → Contact with bounded local search and manual entry. Review
  the name and international phone number before explicitly sending one vCard;
  no other address-book fields are shared. Failed sends retain the review, and
  account/chat guards prevent sending to a stale destination.
- Add own-profile photo replacement and confirmed removal. JPEG/PNG selection
  opens a preview before Save; background preparation handles orientation and
  produces a bounded square JPEG without modifying the original.

## View-once messages and Status navigation

- Show an informational view-once bubble and privacy-safe quoted previews
  instead of omitting these messages. Opening view-once media still requires
  the phone; the desktop does not expose its content or download controls.
  Missing historical payloads cannot be reconstructed locally.
- Make Escape close the Status viewer even if focus moved behind it, while
  preserving nested popup navigation and restoring the previous page/control.
- Add Pause/Resume, keyboard navigation and visible focus to the Status viewer,
  block interaction with the covered chat, and improve header contrast.

## GIFs and stickers

- Add Emoji, GIFs and Stickers tabs, local recent emoji, and reuse of recent or
  starred stickers. Preserve original sticker media when reusing or forwarding.
- Connect GIPHY trending/search and KLIPY featured/search to configured API
  keys. Preview a selected GIF before explicit Send. Debounce and page search,
  bound downloads and decoding, and cancel stale requests.
- Add static sticker creation from JPEG/PNG through the system file picker,
  preview and explicit Send. Preparation runs in the background and creates a
  size-bounded 512-pixel-square WebP. Creation requires an available libwebp
  encoder; builds without it explain the limitation.

## Additional settings parity

- Add opt-in, quiet security-code-change alerts and confirmed default message
  timers for new chats. Explain the unavailable current-default readback and
  retained local history explicitly.
- Read the account's About and available avatar; preserve failed About edits.
  Separate About visibility from the read-only status-broadcast audience.
- Add Standard/HD/Original photo preparation with orientation handling,
  bounded background work and preservation of source files. Original remains
  the default; documents, animations and videos stay unchanged.
- Add optional offline Aspell checking and suggestions in message/caption editors,
  with a mouse/keyboard edit menu and undoable corrections. No automatic
  dependency installation or external spelling service.
- Handle an empty system clipboard safely when evaluating Paste availability.

## Sound alerts and additional settings

- Add separate message/group reaction alerts and sound switches, incoming-call
  alerts (answer on the phone), optional successful-send sounds and sound previews.
- Suppress repeated-message alerts and replayed/removed reaction alerts.
- Add opt-in Status alerts and a separate Linux sound switch. History, duplicate
  delivery, old updates, own updates and muted senders remain quiet. Status
  notification activation preserves the current chat and draft.
- Add per-type automatic media-download settings, retaining manual downloads.
- Add a backend-enforced link-preview network privacy switch, profile-name
  editing, and supported account call/message/unknown-volume privacy controls.
- Keep unsupported calling, Status likes/mentions, account-management and app-lock
  capabilities explicit. This is not full WhatsApp Web feature parity.

## Settings and Escape navigation

- Add searchable Profile, Account, Privacy, Chats, Notifications, Keyboard
  shortcuts, and Help navigation in a bounded sidebar, with clear explanations
  for unavailable official-app controls.
- Add persistent per-profile message/group alerts, notification-body previews
  and Linux notification sounds. Muted chats and history retention are unchanged.
- Add copyable profile identity, wallpaper and emoticon-replacement preferences,
  system/light/dark appearance choices, and additional keyboard shortcuts.
- Escape backs out one level, closing a popup/viewer before a page and returning
  to Chats by default, without quitting the application or clearing drafts.

## Document cards and jump-to-latest

- Replace the separate document **Open** button with a compact, clickable card:
  filled file-type badge, wrapping filename, type and available size. Save to
  the system Downloads folder without launching another app; show progress and
  the saved path, and preserve existing files with numbered filenames.
- Add a circular down-arrow above the composer when scrolling away from the
  newest message. Clicking it returns to the bottom and follows new messages;
  reaching the bottom with the wheel or scrollbar also restores following.

## System file picker

- Use the GTK-native file chooser when a graphical Linux launcher omits desktop
  identification, instead of falling back to the Qt Quick picker. Apply this to
  documents, photos/videos, audio, status media, image saving and chat exports.
- Preserve desktop/theme overrides and headless startup. Recommend the GTK
  platform integration in Debian packages and document setup/fallback behavior.

## Group information

- Add live members, search, available photos and phone numbers, admin badges,
  description and creation metadata to the group-info panel.
- Make contact and group-member names/phone numbers selectable and copyable,
  with small inline copy icons beside each value, keyboard/context-menu copying,
  and copy feedback.
- Add permission-aware member addition/removal/admin actions, invitations and
  confirmed link reset, create-similar-group selection, custom lists, notification
  settings, and confirmed group exit that retains local history.
- Keep large member lists virtualized and surface loading/partial-action failures.
- Identify advanced chat privacy, member tags, and reporting as features that
  still require the official WhatsApp app.

## Lucide icons

- Replace hand-drawn navigation, menu and message-action icons with bundled
  Lucide artwork, including the audio/video play and pause controls.
- Preserve compact button geometry, accessibility labels and theme colors.
  Icons render crisply at the display's pixel density, including with the
  software renderer, without network requests.
- Keep the app logo, status rings and WhatsApp-style receipt marks unchanged.
- Include Lucide/Feather license notices; source builds now require Qt SVG.

## Unread-message divider

- Show a centered unread-count pill on a subtle horizontal band above the first
  unread incoming message, matching the WhatsApp Web reference in both themes.
- Keep its position stable across receipts and older history pages. New incoming
  messages increase the count; duplicate updates do not. Replying clears it,
  and reopening a chat starts a fresh unread batch.
- Read the initial message page and unread boundary from one database snapshot.
  Do not guess a boundary when the required history is unavailable locally.
- Preserve messages arriving during the initial page request and ignore stale
  responses from earlier chat activations.
- Preserve bottom-opening behavior and ordinary mouse-wheel scrolling.

## Image captions

- Fix long captions disappearing below a fixed-height image-preview editor.
  The field and footer now grow together, then scroll for longer text without
  obscuring the image controls. The cursor stays visible when resizing, too.
- Preserve mouse editing, plain-text/RTL paste, Shift+Enter for new lines, and
  the existing send/failure guards.

## Textbox scrollbars

- Fix the scrollbar collapsing to a tiny dash in overflowing message drafts
  and image captions. It now spans the field's height at its trailing edge,
  stays visible while text overflows, and supports dragging as well as mouse
  wheel scrolling.
- Preserve the existing chat-list and conversation scrollbar geometry; the
  correction applies to custom bars hosted by `ScrollView`.

## Large-conversation speed

- Create message menus and reaction popups on demand, and audio controls only
  for audio messages, reducing the work required to display and scroll bubbles.
- Recalculate only affected date separators and combine bursts of sidebar
  refreshes, keeping long conversations responsive as messages arrive.
- Reuse matching cached message rows when opening a chat. Bound the disposable
  reopening cache without removing any saved history.
- Decode inline previews at screen-appropriate resolution while keeping the
  original media available for full-quality viewing and zooming.

## Emoji in textboxes

- Show colored emoji alongside ordinary text in message and image-caption
  editors, including emoji inserted from the picker. Editor content stays
  plain Unicode, not HTML.
- Convert standalone emoticons such as `;-)`, `:-D`, and `:-)` to emoji on
  space/newline completion or Send. Preserve URLs, backtick-delimited code,
  cursor placement, selections, and native Undo/Redo. Existing sent messages
  are not rewritten.

This release also includes all earlier desktop navigation, media sizing,
typing-status and reliability fixes documented in the
[v0.1.6 notes](https://github.com/shukiv/whatsappgo/blob/main/docs/releases/v0.1.6.md).

## App preferences and compact composer controls

- Add a top-toolbar gear opening separate WhatsAppGo settings with local,
  masked GIPHY, KLIPY and legacy Tenor API-key fields. Save provider preferences
  atomically, independently of WhatsApp profiles. GIF discovery requires your
  own provider key; validation occurs on the first request, not Save. Tenor is
  marked retired and cannot be selected.
- Keep the image-preview Send glyph at 24 px inside its 64 px button instead
  of stretching it to 52 px. Tighten attachment/emoji center spacing from 48
  to 40 px while retaining 36 × 44 px click targets.

## Upgrade and compatibility

Upgrade the desktop application and its bundled `whatsappd` and `whatsappctl`
together. Existing account profiles, settings and locally retained history are
preserved; no re-pairing or database reset is required. Disappearing-message
timers still do not expire locally stored history.

Bug reporting opens [WhatsAppGo GitHub issues](https://github.com/shukiv/whatsappgo/issues)
in the default browser. No intake key, in-app form or automatic log upload is
required. Voice and video calls remain unsupported.

## Builds and verification

Release artifacts are the Linux AppImage, Windows installer and portable ZIP,
and macOS Apple Silicon DMG, accompanied by `SHA256SUMS`. Verify checksums before
installation. Builds are unsigned: Windows SmartScreen may warn, and macOS may
require allowing the application in System Settings.

Local verification passes the existing Go suite and vet, all 44 desktop checks,
and isolated light/dark UI, RPC and database probes. Complete cross-platform CI
on the release commit is required before tagging. Live authenticated GIF-provider
requests, contact sends and profile-photo changes have not been exercised against
real accounts; the isolated checks do not send live WhatsApp messages or upload
profile photos.

The release remains a draft until a human reviews and publishes it. Drafts are
not offered by the automatic update checker; the local development installation
is upgraded directly after building the tagged source.
