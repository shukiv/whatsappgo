# WhatsAppGo v0.1.5

## Fixes

- Preserve text drafts, quoted replies, pasted images and captions when sending
  fails. Late acknowledgements cannot clear newer drafts or another chat's input.
- Preserve deleted/edited messages and rich metadata when phone-number and LID
  histories are consolidated, including stars, previews, waveforms and receipts.
- Recover older attachments from their original archive identities after a
  cache clear, including profiles consolidated by earlier versions.
- Mark every active and archived conversation read, not just the first page.
- Restore pointer-anchored mouse-wheel zoom in the image viewer.
- Synchronize privacy settings across account switches, reconnects and incoming
  updates; expose Online separately from Last seen.
- Keep edited link previews with the correct message revision; preserve media
  selection and starred-message scopes; pause status-story progress correctly.
- Include the own-reaction rendering correction since v0.1.4.

## Bug reporting

Reports now go to `bugs.jabali-panel.com`, program `whatsappgo`, instead of GitHub
Issues. An operator-issued intake key must be configured for the app-owned
backend. No key is bundled and no private chat logs are automatically uploaded.
See [key setup](https://github.com/shukiv/whatsappgo/blob/v0.1.5/docs/BUG_REPORTING.md).

## Compatibility and verification

Existing profiles and the maximum-local-history retention policy are preserved.
Disappearing-message timers still do not expire locally stored conversation
history. Metadata discarded by a previous merge cannot be reconstructed
automatically.

Regression coverage includes failed sends, cross-chat acknowledgements, alias
merges, archived-media restoration, mark-all-read pagination and mocked intake
submissions. Package metadata now identifies this release as 0.1.5.

Builds are unsigned. Windows SmartScreen may warn about the installer, and macOS
may require allowing the application in System Settings. Verify downloads
against the accompanying `SHA256SUMS` before installation.
